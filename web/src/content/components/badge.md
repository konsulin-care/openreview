# Badge Component

The Badge component displays status information with color coding.

## Props

- `variant: 'stable' | 'experimental' | 'planned'`

## Usage

```astro
<Badge variant="stable">Stable</Badge>
<Badge variant="experimental">Beta</Badge>
<Badge variant="planned">Planned</Badge>
```
